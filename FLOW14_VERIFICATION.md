## Scope and Architecture

The reporting path preserves the established AMMS separation of concerns:

> **Controller → FormRequest → Permission and AMMS organizational scope → read-only Query Service → allowlisted API Resource → Persian/Dari RTL UI**

The backend owns all business metrics. The React Reports Center presents server-defined metric cards, charts, registers, filters, and export lifecycle states; it does not recompute authoritative values in the browser. Date ranges are half-open and carry a declared timezone. Reporting queries use allowlisted filters and sorts, distinct Meeting identities, authoritative current Minute Versions, invalidation-aware official attendance, and applied historical event timestamps.
